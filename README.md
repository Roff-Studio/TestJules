## API Key Management

API keys are crucial for interacting with external services like xAI and Pump.fun. They authenticate your requests and grant access to specific functionalities.

**Storage:**
All API keys and sensitive credentials for this project are stored in a file named `.env` located in the project root.

**Security:**
*   **IMPORTANT:** The `.env` file contains sensitive information. It **MUST** be added to your `.gitignore` file and **NEVER** be committed to version control (e.g., Git, GitHub). If `.gitignore` does not exist, create it and add `.env` to it.
*   Always keep your API keys and private keys confidential. Do not share them publicly or commit them to version control.

**Instructions for API Keys:**

### xAI API Key (`XAI_API_KEY`)
1.  The `XAI_API_KEY` (format `xai-...`) must be generated manually from the official xAI console: [https://console.x.ai/](https://console.x.ai/).
2.  Once you have generated your key, copy it.
3.  Open the `.env` file in the project root and paste the key as the value for `XAI_API_KEY`. For example:
    ```
    XAI_API_KEY="xai-yourGeneratedKeyHere"
    ```

### Pump.fun Keys (`PUMPFUN_API_KEY`, `PUMPFUN_PRIVATE_KEY`, `PUMPFUN_PUBLIC_KEY`)
1.  The Pump.fun keys (`PUMPFUN_API_KEY`, `PUMPFUN_PRIVATE_KEY`, `PUMPFUN_PUBLIC_KEY`) will be generated by the `src/utils/generate_pumpfun_keys.py` script. (Note: The actual generation logic is pending implementation in the script).
2.  Once generated, these keys should also be securely stored in the `.env` file.

General security advice: "Always keep your API keys and private keys confidential. Do not share them publicly or commit them to version control."
